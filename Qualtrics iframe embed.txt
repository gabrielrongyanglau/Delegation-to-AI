EMBEDDING THE STUDY 6 AI DELEGATION TASK IN QUALTRICS VIA <IFRAME>
==================================================================

Replace https://YOUR-APP.vercel.app below with your actual Vercel URL (in both
places: the iframe src and the origin check in the JavaScript).


STEP 1: Create the embedded data fields
---------------------------------------
Survey Flow -> Add a New Element -> Embedded Data -> add these fields, with
empty values, ABOVE the block containing the task question:

    d6_delegation          self | recommend | approve | autonomous
    d6_action1             response to Granite 14 (empty for self)
    d6_action2             response to Atlas 14 after reconsidering (else empty)
    d6_final_laptop        laptop selected, e.g. Atlas 14
    d6_final_valid         1 if it meets all five requirements, otherwise 0
    d6_final_source        agent | own
    d6_accepted_flaw       delegators: 1 if they went along with Granite 14, else 0
    d6_responsibility      everyone: 1 (Entirely me) to 7 (Entirely the agent)
    d6_panels              JSON: information panels opened on each screen
    d6_outputs             JSON: agent outputs shown and their source
    d6_events              JSON: timestamped log of every screen, panel and choice
    d6_reloads             times the task was reloaded mid-task and resumed (0 normally)
    d6_complete            1 once the task is finished, otherwise 0

The README lists every code these fields can take.


STEP 2: Add the iframe to the question
--------------------------------------
Create a Text/Graphic question in the Study 6 block, after the AI Delegation
Scale. Open the rich-text editor, switch to HTML view (the "<>" button), and
paste:

<iframe
  src="https://YOUR-APP.vercel.app/?rid=${e://Field/ResponseID}"
  title="AI Delegation Task"
  style="width:100%; height:900px; border:1px solid #dce1e8; border-radius:12px;"
  allow="clipboard-write">
</iframe>

The task scrolls inside the frame, so a shorter height still works.

Keep ?rid=${e://Field/ResponseID} in the src. Qualtrics replaces it with the
response ID, which lets the task save each participant's progress separately.
If the page is refreshed or the survey reopened, the participant resumes where
they left off instead of starting again, and d6_reloads counts how often that
happened. Without ?rid, progress only survives a refresh in the same tab.


STEP 3: Add the receiver and lock the Next button
-------------------------------------------------
On the SAME question, open the JavaScript editor (gear icon -> Add JavaScript)
and replace its contents with:

Qualtrics.SurveyEngine.addOnReady(function () {
  var question = this;

  // Participants cannot move on until the task is finished.
  question.hideNextButton();

  window.addEventListener('message', function (event) {
    // Only accept messages from the deployment, never from any other frame.
    if (event.origin !== 'https://YOUR-APP.vercel.app') return;
    var d = event.data;
    if (!d || d.type !== 'ai-delegation-task') return;

    function set(name, value) {
      Qualtrics.SurveyEngine.setEmbeddedData(name, value);
    }
    set('d6_delegation', d.delegation);
    set('d6_action1', d.action1);
    set('d6_action2', d.action2);
    set('d6_final_laptop', d.finalLaptop);
    set('d6_final_valid', d.finalValid);
    set('d6_final_source', d.finalSource);
    set('d6_accepted_flaw', d.acceptedFlaw);
    set('d6_responsibility', d.responsibility);
    set('d6_reloads', d.reloads);
    set('d6_panels', JSON.stringify(d.panels));
    set('d6_outputs', JSON.stringify(d.outputs));
    set('d6_events', JSON.stringify(d.events));
    set('d6_complete', d.complete ? 1 : 0);

    if (d.complete) question.showNextButton();
  });
});


HOW THE DATA CAPTURE WORKS
--------------------------
An iframe cannot write Qualtrics embedded data directly: it is a separate
document on a different origin. The task page calls window.parent.postMessage()
after every action, and the receiver above writes the fields. The origin check
stops any other embedded content on the page from spoofing the data.


IF THE IFRAME RENDERS BLANK
---------------------------
Open the browser console. A message mentioning "frame-ancestors" means the
Content-Security-Policy in next.config.mjs does not list the domain your
survey is served from. The current policy allows https://*.qualtrics.com,
which covers most institutions; add your specific domain there if yours
differs.
